# Zenith Digital Agency website (frontend)

This folder is the whole website. Open the `frontend` folder in VS Code.

## Run it (first time)
1. In VS Code terminal, run:  npm install
2. Then run:                  npm run dev
3. Open http://localhost:3000 in your browser
4. Stop the server with Ctrl+C

## Editing content
All text, services, locations, stats, FAQs and contact details live in src/data/site.ts.
Layout and animations live in src/components and src/app.
